## Entry 1

### Date

2026-06-10

### Topic

Phase 0 project planning

### What I learned

I learned that before coding, I should define the problem, target users, MVP features, architecture, and technical decisions.

### Mistake or confusion

I was thinking about adding many features too early, like full chatbot, login, charts, multilingual UI, and dark/light mode.

### How I fixed it

I separated features into MVP and later features. I decided to build a small, useful, and testable version first.

### Engineering lesson

A good project is not the one with many features. A good project solves a clear problem with a simple and working system.

## Entry 3

### Date

2026-06-11

### Topic

Homepage UI completion and local FAQ widget

### What I learned

I learned how to improve a homepage by combining a video hero, glass navbar, short value sections, support cards, a final CTA, and a small floating FAQ widget.

### Mistake or confusion

The project notes still said the FAQ widget should come later, but the homepage scope changed and the widget was added as local JavaScript only.

### How I fixed it

I kept the FAQ simple with prepared answers in the frontend. I did not add AI API calls, backend routes, login, database logic, or form submission logic.

### Engineering lesson

When project scope changes, update the context files so future work follows the real current state instead of old notes.

Premium hero transition

### What I learned

I learned that a video hero can feel more connected to the page by adding a soft bottom gradient, subtle glow, and a small overlap with the first content section.
