# OSBT Student Success Hub

## Project idea
A modern student helper website for OSBT students and candidates.

## Problem
Students and candidates need quick access to repeated questions, school events, and a simple way to submit requests.

## Target users
- New candidates
- Current students
- Admin / school staff

## MVP features
- Modern homepage
- Floating FAQ widget on homepage
- Events page
- Student request form
- Basic admin dashboard
- WhatsApp quick contact button
- Button to open my full AI Assistant app

## Not included now
- Full AI chatbot inside this website
- Login system
- Multilingual UI
- Charts
- CSV export
- Dark/light mode
